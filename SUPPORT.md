# Soporte

## ¿Dónde pedir ayuda?

- **Dudas de uso o configuración**: abre un Issue con contexto.
- **Errores reproducibles**: usa la plantilla de Bug Report.
- **Propuestas de mejora**: usa la plantilla de Feature Request.
- **Vulnerabilidades de seguridad**: sigue [SECURITY.md](SECURITY.md).

## Qué incluir para recibir ayuda más rápido

- Sistema operativo y versión.
- Pasos para reproducir.
- Resultado esperado vs resultado actual.
- Logs o mensajes de error relevantes.
